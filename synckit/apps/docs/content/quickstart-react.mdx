# Quickstart — React

Ten minutes from zero to live cursors and comments.

## 1. Install

```bash
pnpm add @synckit/react @synckit/client
```

## 2. Mint client tokens on your backend

Your server exchanges its secret API key for a short-lived JWT per user.
The API key never reaches the browser.

```ts
// e.g. an Express/Next route: GET /api/synckit-token
const response = await fetch("https://api.your-synckit.com/v1/tokens", {
  method: "POST",
  headers: {
    authorization: `Bearer ${process.env.SYNCKIT_API_KEY}`,
    "content-type": "application/json",
  },
  body: JSON.stringify({
    externalUserId: user.id, // your user id
    displayName: user.name, // shown on cursors & comments
  }),
});
const { token } = await response.json();
```

## 3. Create the client and wrap your app

```tsx
import { createClient } from "@synckit/client";
import { SyncKitProvider, RoomProvider } from "@synckit/react";

const client = createClient({
  url: "wss://api.your-synckit.com/v1/realtime",
  tokenProvider: async () => {
    const response = await fetch("/api/synckit-token");
    const { token } = await response.json();
    return token; // called again automatically when the token expires
  },
});

export function App() {
  return (
    <SyncKitProvider client={client}>
      <RoomProvider id="document-42" initialPresence={{ cursor: null }}>
        <Editor />
      </RoomProvider>
    </SyncKitProvider>
  );
}
```

## 4. Add presence, cursors, comments

```tsx
import {
  LiveCursors,
  PresenceAvatars,
  CommentsThread,
  useUpdateMyPresence,
  useOthers,
} from "@synckit/react";

function Editor() {
  const updatePresence = useUpdateMyPresence(); // throttled for you
  const othersCount = useOthers((others) => others.length);

  return (
    <div onPointerMove={(e) => updatePresence({ cursor: { x: e.clientX, y: e.clientY } })}>
      <PresenceAvatars /> {othersCount} collaborators online
      <CommentsThread anchor={{ blockId: "intro" }} />
      <LiveCursors />
    </div>
  );
}
```

Every component is themeable via CSS variables (`--synckit-accent`,
`--synckit-bg`, `--synckit-radius`, …) — see the SDK reference.

## 5. Broadcast your own events

```tsx
import { useBroadcastEvent, useEventListener } from "@synckit/react";

const broadcast = useBroadcastEvent();
broadcast("card:moved", { cardId, toColumn });

useEventListener("card:moved", (payload, from) => {
  applyMove(payload);
});
```

That's the whole surface for most apps. The
[demo board](https://github.com/lutimir/webosockets/tree/main/synckit/apps/demo)
is ~400 lines and uses everything above.
